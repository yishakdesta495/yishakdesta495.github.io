# Yishak Baraki Desta — Professional Portfolio

This is a static website built for free deployment on GitHub Pages.

## Files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and subtle scroll reveal
- `assets/` — selected portfolio images and public documents

## Recommended GitHub Pages deployment
1. Create a GitHub account if you do not already have one.
2. Create a new public repository named exactly: `YOURUSERNAME.github.io`
3. Upload everything inside this folder to the repository root.
4. Commit the files.
5. GitHub Pages should publish automatically at:
   `https://YOURUSERNAME.github.io/`

If it does not, open **Settings → Pages**, set Source to **Deploy from a branch**, select **main** and **/(root)**, then save.

## Privacy choices already made
The public site deliberately does NOT include:
- passport or identity-document details
- residential address
- phone number
- referees’ private contact details
- recommendation letter
- high-school transcript
- full certificate scans

## Before publishing
Open `index.html` in a browser and review:
- name spelling
- email
- LinkedIn URL
- dates and role titles
- public PDFs you are comfortable sharing
